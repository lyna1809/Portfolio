# 🌐 Mon Portfolio Web Personnel

Ce portfolio a été réalisé dans le but de mettre en pratique les compétences que j'ai acquises en **HTML** et **CSS**, dans le cadre d'un apprentissage personnel du développement web.

## 🎯 Objectif

Créer un **site web personnalisé** présentant mon parcours académique, mes projets, mes compétences techniques, mes expériences et mes centres d’intérêt, le tout dans un design clair, responsive et soigné.

## 🛠️ Technologies utilisées

- HTML5
- CSS3 (avec animations simples et transitions)

## 💡 Contenu du site

Le portfolio est composé des sections suivantes :

- **Page d'accueil** avec une introduction personnalisée
- **Formations** : présentation chronologique de mon parcours universitaire
- **Projets** : chaque projet contient un lien vers son code GitHub et une description claire de son objectif
- **Compétences techniques** : langages, outils, environnements
- **Expériences personnelles**
- **Contacts** : email, téléphone, GitHub, LinkedIn
- **Soft skills** : autonomie, rigueur, communication, etc.


## ✨ Design et animation

- Mise en page structurée en **sections bien définies**
- **Transitions douces** et **animations CSS** pour améliorer l’expérience utilisateur
- Adapté à une lecture simple et agréable
